# Pocket Core Matrix

Last updated: 2026-04-27

This tracks public Pocket target bring-up status. Promote a core to
`Hardware OK` only after a real Analogue Pocket test confirms boot, video,
audio, and basic controls. A clean Quartus/APC build alone is tracked as
`Build OK / Needs HW test`.

## Status Legend

| Status | Meaning |
| --- | --- |
| Hardware OK | User tested on Pocket and reported the core works. |
| Hardware OK / Issues | User tested on Pocket and the core runs, but a target-visible issue remains. |
| Hardware retest pending | A prior hardware failure has a package/metadata fix and needs a fresh SD retest. |
| Hardware frozen / fails | User tested on Pocket and the core loads but does not reach working gameplay. |
| Hardware blocked / missing assets | User tested on Pocket but the package is missing required instance JSON or ROM payloads. |
| Build OK / Needs HW test | APC build passed timing, but no hardware result yet. Notes say whether SD copy is complete or pending. |
| Blocked before build | Export/preflight failed before Quartus. |
| Build failed | Quartus/APC started but failed analysis, synthesis, fitter, or timing. |
| No RTL / Schematic Only | The core directory is present, but there is no RTL implementation to export or build yet. |
